# Contacts guidance

The local Rolodex owns saved contacts and revisions. Compose household_contacts_* and document tools as useful for scans, corrections and retrieval. No guide load, formal goal or mandatory pre-save review is required. Each supplied card can retain its own record and source/extraction references; similarity is evidence for matching, not an automatic merge.

Local OCR and exact supporting quotes can ground interpreted fields. Report unreadable or uncertain details honestly and retain the original card even when extraction fails. Literal field matches can be grounded automatically; observations explain normalization using actual evidence. Explicit fields/patches choose the saved values. An extraction receipt establishes an actual OCR pass; interpretation of old evidence is not a new pass.

Current revisions prevent overwriting newer changes. revise supports patch.set and patch.remove, or deliberate full replacement. Ordinary human corrections and OCR redo requests remain natural prompts. Later extraction alone does not silently replace a saved record under the current contacts API. Preserve unaffected fields and sources. Search/get support follow-ups. Current private/shared scope and explicit sharing permissions govern disclosure. Inspect an uncertain write before repeating it.
